# Task 27 – Distribution Analysis

## Aim
To analyze the distribution of numerical data using a histogram.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
This project uses a histogram to visualize the distribution
of student marks and understand the spread of numerical data.

## Observations
1. Student marks range from 45 to 90.
2. The histogram shows the frequency of marks across intervals.
3. The marks are evenly spaced, with no extreme outliers.

## Conclusion
Histogram visualization helps us understand the concentration
and spread of numerical data.
